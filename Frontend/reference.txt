| Don't Use                    | Reason                                                 |
| ---------------------------- | ------------------------------------------------------ |
| Glassmorphism                | Doesn't match the rest of the application              |
| Heavy Blur Effects           | Looks inconsistent                                     |
| Floating Gradient Blobs      | Too decorative for enterprise UI                       |
| Neon Colors                  | Breaks brand consistency                               |
| Dark Dashboard Theme         | Website is primarily light themed                      |
| Multiple Font Families       | Use only Inter                                         |
| Oversized Icons              | Keep icons between 20–24px                             |
| Heavy Shadows (`shadow-2xl`) | Use subtle elevation only                              |
| Random Accent Colors         | Stick to Emerald → Teal → Cyan branding                |
| Inconsistent Border Radius   | Use only `rounded-lg`, `rounded-xl`, or `rounded-full` |


| Principle               | Description                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Consistency**         | Every page should feel like part of the same product.                                                       |
| **Professionalism**     | Prioritize clarity and trust over visual effects.                                                           |
| **Accessibility**       | Maintain high contrast, readable typography, and proper spacing.                                            |
| **Minimalism**          | Remove unnecessary decorations; let content lead.                                                           |
| **Enterprise First**    | Follow the design language of Microsoft Learn, Azure Portal, GitHub, and Atlassian.                         |
| **Brand Identity**      | Use the Emerald → Teal → Cyan gradient sparingly for logos, highlights, and active elements only.           |
| **Reusable Components** | Build shared Typography, Buttons, Cards, Inputs, and Containers instead of styling each page independently. |
